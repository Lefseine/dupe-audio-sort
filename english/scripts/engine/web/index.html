🎯 Bit Alignment Verification AccurateRip / CTDB

Calculate the discID from the whole-disc cue TOC, compute AccurateRip v1/v2 checksums track by track, and compare against the global database — this is the only method that can prove "this rip is bit-for-bit identical to everyone else's," stronger than any spectral or dynamic metric. Single-track files have no TOC and physically cannot be verified — you'll be told this explicitly.

🔊 Library-Wide Loudness Normalization ReplayGain · rsgain

Measure each track's loudness (LUFS) and suggested gain to eliminate the "louder sounds better" comparison bias. By default this is a read-only scan (performed on temporary copies, with zero changes to the original folder); ReplayGain tags are written only after you confirm, changing tags only and never the audio stream — JRiver / foobar / phone players all apply them automatically.
